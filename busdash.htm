Configure stops here — no URL needed. Type your stops into the “Stops” box above and click Load stops. This works on Android (where content:// blocks URL query strings and file://). Use Save as file to download a personalised copy with your stops baked in, then open that file any time.

URL parameters (desktop browsers only): pass stops and route filters in the address bar:

bus-dashboard.html?stops=490000077C|Euston:390,91;490000049S|Kings+Cross:46,214;490G00000351|Marylebone

Format per stop: NaptanId[|Label[:route,route]] — the stop ID comes first, an optional label after |, and an optional route list after :. Separate stops with ;. Omit routes to show all. Use + or %20 for spaces in labels. Optional: &key=YOUR_APP_KEY (500 req/min) and &interval=30 (refresh seconds).

Higher rate limits (optional): Anonymous access is capped at 50 requests/min, which is plenty for personal use. For continuous multi-stop monitoring, register at the TfL API Portal, subscribe to the free 500 Requests per min product, copy your Primary key from the Profile page, and add &key=... to the URL (or paste it below).
